Posiciones con CSS

Esta práctica consiste en aplicar las propiedades de posicionamiento en HTML con CSS, estas nos permiten controlar la ubicación de los elementos dentro de una página web.

¿Qué es el posicionamiento?

Dependiendo de la posición, un elemento puede permanecer en su lugar, desplazarse, colocarse encima de otro o permanecer fijo en la pantalla.

Posiciones que estudiaremos:

  • static
  • relative
  • absolute
  • fixed
  • sticky
Estilo Static: Los programadores trabajan constantemente con números, lógica y estructuras para construir soluciones.

Estilo Relative: El día del programador se celebra tradicionalmente el día 256 del año.

Estilo Absolute: El número 256 tiene un significado especial en informática.

Estilo Sticky: 28 = 256, está relacionado con los bits utilizados para representar 256 valores diferentes.

🕊️

Nota: Para probar cómo funcionan las posiciones (especialmente relative, absolute y sticky), asegúrate de tener definidos sus estilos correspondientes en tu CSS.
